# 🧾 สลิปเซ้นส์

ระบบอ่านสลิปโอนเงิน/จ่ายบิลอัตโนมัติ แล้วแยกค่าใช้จ่ายเป็นหมวดหมู่

- **อ่านด้วย Gemini** ที่เซิร์ฟเวอร์ (API key อยู่ฝั่งเซิร์ฟเวอร์ ไม่อยู่ในหน้าเว็บ)
- **iPhone ส่งสลิปเองทุกวัน** ผ่าน iOS Shortcuts โดยไม่ต้องเปิดแอพ ([SHORTCUT.md](SHORTCUT.md))
- เก็บข้อมูลใน **SQLite** บนเซิร์ฟเวอร์ของคุณ เปิดดูได้จากทุกเครื่อง
- จัดหมวดอัตโนมัติ และจำว่า "ผู้รับนี้ = หมวดนี้" เมื่อคุณแก้
- กันสลิปซ้ำ (ทั้งรูปเดิมและข้อมูลเดิม), สลิปที่อ่านไม่ครบเข้าคิว "รอตรวจ"
- หมวด "ชำระบัตรเครดิต" ไม่นับรวมในยอด เพื่อไม่ให้ซ้ำกับรายการที่รูด
- สรุปรายเดือนแยกหมวด, เพิ่ม/แก้/ลบเอง, ส่งออก CSV (เปิดใน Excel ได้)

## Deploy
ดู [DEPLOY.md](DEPLOY.md) – Docker + Caddy บน VPS

## โครงสร้าง
- `server.js` – เซิร์ฟเวอร์ Node 22 (ไม่มีไลบรารีเสริม): API, Gemini, SQLite
- `parser.js` – หมวดหมู่, คีย์เวิร์ด, พรอมต์ให้ Gemini (ใช้ร่วมกันทั้งเว็บและเซิร์ฟเวอร์)
- `index.html`, `app.js`, `style.css` – หน้าเว็บ (PWA)

## ทดสอบ
```bash
node test/parser.test.js
node --disable-warning=ExperimentalWarning test/server.test.js   # ใช้ Gemini จำลอง ไม่ต้องใช้เน็ต
```

ปรับหมวด/คีย์เวิร์ดได้ที่ `CATEGORIES` ใน `parser.js`
