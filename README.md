# 🧾 สลิปเซ้นส์

เว็บแอพ (PWA) สแกนสลิปโอนเงิน/ใบเสร็จจากรูปในมือถือ แล้วแยกค่าใช้จ่ายเป็นหมวดหมู่อัตโนมัติ

- อ่านด้วย Gemini ได้ (ตัวเลือก ใส่ API key เอง รูปจะถูกส่งไปที่ Google) ไม่งั้นอ่านในเครื่อง
- หมวด “ชำระบัตรเครดิต” ไม่นับรวมในยอดค่าใช้จ่าย เพื่อไม่ให้ซ้ำกับรายการที่รูด
- เลือกรูปสลิปจากแกลเลอรี/ถ่ายใหม่ได้ครั้งละหลายใบ
- OCR ภาษาไทย+อังกฤษในเครื่อง ด้วย [Tesseract.js](https://github.com/naptha/tesseract.js) (รูปไม่ถูกส่งไปไหน)
- ดึง **จำนวนเงิน / วันที่-เวลา (รองรับ พ.ศ.) / ผู้รับ-ร้านค้า** แล้วจัดหมวดหมู่ด้วยคีย์เวิร์ด
- จำว่า “ผู้รับคนนี้ = หมวดนี้” เมื่อคุณแก้หมวด ครั้งต่อไปจะจัดให้เอง
- สรุปรายเดือน แยกตามหมวด, แก้ไข/ลบ/เพิ่มเอง, ตรวจสลิปซ้ำ, ส่งออก CSV (เปิดใน Excel ได้)
- ติดตั้งลงหน้าจอโฮมได้ และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ใช้งานบนมือถือ
ต้องเปิดผ่าน HTTPS (หรือ localhost) จึงจะติดตั้งเป็นแอพได้ วิธีง่ายสุดคือเปิด GitHub Pages ของ repo นี้
(Settings → Pages → Deploy from branch) แล้วเปิดลิงก์บนมือถือ → เมนูเบราว์เซอร์ → “เพิ่มลงหน้าจอโฮม”

ทดสอบบนเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## Deploy บน VPS ของตัวเอง
ดู [DEPLOY.md](DEPLOY.md) – Docker + Caddy, เก็บ Gemini key ไว้ฝั่งเซิร์ฟเวอร์

## อัตโนมัติบน iPhone
ดู [SHORTCUT.md](SHORTCUT.md) – ตั้ง Shortcuts ให้ส่งสลิปใหม่เข้าแอพเองทุกวัน (ลิงก์รูปแบบ `index.html#import=...`)

## ทดสอบตัวอ่านข้อความ
`node test/parser.test.js` และ `node test/server.test.js`

## ปรับแต่ง
แก้หมวดหมู่และคีย์เวิร์ดได้ที่ `CATEGORIES` ใน `parser.js`

> OCR อาจอ่านผิดได้ จึงมีหน้าตรวจสอบ/แก้ไข ปิด “บันทึกอัตโนมัติ” ถ้าอยากตรวจทุกใบ
